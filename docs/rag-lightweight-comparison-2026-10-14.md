# RAG 두 차례 경량화 비교

기준: Git 커밋 `1036030`의 경량화 전 파일과 현재 로컬 파일. 중간 1차 상태는 현재 diff에서 입력 축소와 GPT OFF 분기를 구분해 설명하며 별도 커밋으로 저장된 버전은 아닙니다.

| 항목 | 경량화 전 | 1차 | 현재 2차 |
|---|---|---|---|
| XLSX 검색·성분별 근거·함유/혼입·수동검토 보호 | 적용 | 유지 | 유지 |
| GPT 근거 검토 | 로컬 통과 상품마다 수행 | 유지, 입력 축소 | 기본 OFF, on 복원 가능 |
| 전송 입력 | 전체 검색행/마스터 메타데이터와 원문 중복 | 핵심 ID/인용/정책, 원문1회 | OFF일 때 생성/전송 자체 없음 |
| 최종 통과 | 로컬 통과+GPT 검토 | 동일 경로 | 로컬 근거 통과만으로 PASS |

## RAG와 별개로 변경된 추천 기능

| 파일 | 경량화 전 | 현재 | RAG와의 관계 |
|---|---|---|---|
| selector.py | 선택LLM후보25개 | 10개 | 추천 상품 선택, RAG 검색 제한 아님 |
| agent.py | 최종탈락 후 자동15후보검사 | 자동보충제거 | 대체흐름이 RAG를 호출하던 것이며 RAG 자체기능 아님 |
| agent.py | 상품별제외사유출력 | 챗봇에서숨김 | 표현변경, 판정규칙변경 아님 |

재확인: `git diff 1036030` 기준 allergen_dictionary.py, allergen_context.py, evidence_policy.py, rule_engine.py, extractor.py는 변경이 없습니다. RAG 자체 변경은 allergen_rag.py의 입력축소/중복직렬화제거와 GPT OFF 반환분기입니다. main.py의 상태표시와 .env.example의 검토스위치는 설정/관측 변경입니다.

검색·생성 캐시는 전에도 있었으며 새로 추가된 기능은 아닙니다. source_texts/사전 raw/행·시트 정보는 내부 rag에서 유지합니다. 100근거/12000문자 상한은 GPT 입력 제한이며 현재OFF분기는 그 전에 끝나므로 로컬검토상한으로 적용되지는 않습니다.

## 검증 및 남은 문제

- 전체 자동 테스트166개 통과. 외부 GPT/실사용DB 수정 없음.
- 가짜 GPT가 추가확인을 요구하는 동일 쌀·설탕 사례: on=UNVERIFIED/가짜호출1회, off=PASS/호출0회. 함유우유는 양모드BLOCK, 취급시OCR은UNVERIFIED, 전분·밀 수동근거는UNVERIFIED이며 모두 GPT호출0회.
- 따라서 1차는 전달/호출부담 축소, 2차는 검증단계 자체 생략으로 결과가 달라질 수 있습니다. 판정동등성/정확도향상을 주장하지 않습니다.
- 기존 발견한 마케팅/섭취안내가 원재료로 인정되는 문제는 남아 있습니다. OFF모드는 GPT의 추가확인 기회도 없으므로 구간별 원재료 품질 검사가 우선입니다. 공식표시 완전성도 확인하지 못합니다.
- SHORTLIST10개를 넘는 요청은 알고리즘 선택으로 넘어가고, 예산조합/보충은 전체 후보를 사용합니다. 최종탈락 후 추천개수가 부족해질 수 있습니다.
- KAC_RAG_GPT_REVIEW의 off/on 외 값은 현재 on처럼 동작합니다. 오타 검증 및 정책/프롬프트 버전을 포함한 최종 캐시 개선은 후속 권장사항입니다.
